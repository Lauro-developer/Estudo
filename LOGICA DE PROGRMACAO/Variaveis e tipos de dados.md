Depois de entendermos como funciona a logica de programacao (sua base), temos suas variaveis e seu tipos de dados.

*VARIAVEL* = Basicamente é onde vamo guardar um valor. Imagina como se fosse uma caixa, no qual temos que armazenar um dado valor.

ATRIBUICAO: Para atriuir um valor a uma variavel, usando o = para fazer isso. exemplo: 
                    IDADE (nome da veriavel) = 23 (valor)

existem 3 tipos de dados que podemos utilizar:

    -INTEIRO (int): Trata somente numeros inteiros, ou seja, sem virgula ou casa decimal;
    -REAL (Float/double): Trata numeros reais, ou seja, numero com virgula e casa decimal;
    -BOOLEANO: Esse tipo de dado retorna somente TRUE ou FALSE (verdadeiro ou falso);
    -CONSTANTES: Sao valores que nao mudam;
